# Web

Favicons, app icons and a link-preview image for websites.

| File | What it's for | Size |
| --- | --- | --- |
| [favicon.svg](favicon.svg) | Browser tab icon; black on light themes, white on dark | any |
| [favicon.ico](favicon.ico) | Tab icon for older browsers and search results | 16, 32, 48 |
| [apple-touch-icon.png](apple-touch-icon.png) | iPhone and iPad home screen | 180×180 |
| [icon-192.png](icon-192.png) | Android and web-app icon | 192×192 |
| [icon-512.png](icon-512.png) | Web-app icon and splash screen | 512×512 |
| [og-image.png](og-image.png) | Link preview in Discord, social posts and chats | 1200×630 |

The square icons have room around the mark, so they also work as "maskable"
icons that Android crops to a circle or rounded square.

See [the guide](../README.md) for how to use these files.
