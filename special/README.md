# Special marks

Versions of the mark for occasions, one folder per occasion. Use each only
when the [Marks](../guide/marks.md#special-marks) page says to. Each folder
has the mark as SVG and as a 1024 px transparent PNG, and a 1024 px avatar
on a dark square for profile pictures.

| Occasion | Folder |
| --- | --- |
| Pride | [`pride/`](pride/) |

See [the guide](../README.md) for how to use these files.
