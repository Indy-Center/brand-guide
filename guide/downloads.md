# Downloads

Every file, with a direct link. A link opens the file in your browser; save
it from there, or right-click the link (long-press on a phone) and choose to
save or download it. Before you use them, read
[Marks](marks.md); they're Indy Center's, used as described in
[TRADEMARKS.md](../TRADEMARKS.md).

**Not sure which one?** For most things you want the
[white logo PNG](https://raw.githubusercontent.com/Indy-Center/brand-guide/main/logo/indy-center-logo-white.png)
on a dark background, or the
[avatar](https://raw.githubusercontent.com/Indy-Center/brand-guide/main/avatar/indy-center-avatar.png)
for a profile picture.

PNG files work everywhere. SVG files stay sharp at any size, for designers
and websites.
