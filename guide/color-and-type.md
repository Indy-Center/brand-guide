# Color and type

> **This page is a placeholder.** Indy Center hasn't chosen brand colors or
> fonts yet. Until it does, this page describes what flyindycenter.com uses
> today, so new material can match it.

## Colors in use today

The site is dark, with a sky-blue accent.

| Name | Hex | Used for |
| --- | --- | --- |
| Night | `#070F13` | The near-black in the original logo artwork; avatar and link-preview backgrounds |
| Page | `#111827` | Page background |
| Surface | `#1E293B` | Cards, panels and the header |
| Border | `#334155` | Lines around cards and tables |
| Sky | `#0284C7` | Main buttons (`#0369A1` on hover) |
| Sky light | `#38BDF8` | Links and highlights on dark backgrounds |
| Text | `#FFFFFF` | Headings |
| Text soft | `#D1D5DB` | Body text |
| Text muted | `#9CA3AF` | Captions and fine print |

The logo and mark stay **white or black** whatever the colors around them.
See [Marks](marks.md).

## Type in use today

- The site uses each device's **system font** (the default sans-serif).
- Headings are set **bold or semibold**; small section labels in **capitals
  with wide letter spacing**.
- VATSIM IDs (CIDs) and ratings are set in a **monospaced** font.
- The logo's name is drawn as part of the logo. Don't retype it.

The logo's name is set in **Source Sans 3**: "Indy" in Black, "Center" in
Light. It's free from [Google Fonts](https://fonts.google.com/specimen/Source+Sans+3).
For graphics where you choose the font, use it: Bold or Black for headings,
Regular or Light for text.
