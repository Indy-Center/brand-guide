# Avatar

A square profile picture: the white mark on a dark square, padded so circular
crops don't clip it. Use it for the profile picture on any platform: Discord,
Twitch, YouTube, X, Instagram, Facebook, TikTok, GitHub and the like. Upload
the PNG; each platform scales it down itself.
